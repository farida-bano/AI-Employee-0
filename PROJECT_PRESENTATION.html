⚙️ How It Works

Create Task

User creates a .md file in Bronze/Inbox with task description

Detect & Queue

Vault Watcher monitors every 5 minutes and moves task to Needs_Action

Analyze & Plan

Claude AI Agent generates execution plan with safety checks

Execute

System executes steps sequentially (file ops, API calls, business logic)

Complete

Success → Move to Done | Failure → Log error and retry
